## Body

BBC News reported that artificial intelligence tools surfaced programming defects in PHP that had sat unnoticed for a long time, and that the findings prompted a rare global security response.

PHP is a language a large share of ordinary websites still run on. That sentence is desk background, not a new measurement from BBC News. The report, in the summary used here, does not name a version, a vendor bulletin, or a count of affected hosts. If you need those, read the BBC News story and the notices it points to. This page will not guess them.

What the report does establish is the shape of the event. The defects were old. AI is what brought them up. The response was wide enough that BBC News called it rare and global. That combination is the news. A bug in a niche app is a ticket. A defect in a common web language, found late, becomes a queue of people trying to patch at once.

The practical half is local and dull, which is the point. If you run a site, ask whoever hosts it whether PHP is in the stack. Then ask whether the host has applied the fixes in the current maintainer notices. Do that with the notices open. BBC News is the source for the scramble. It is not a patch file, and it is not a command this desk is willing to invent.

Two limits should stay visible. This desk has not reviewed the vulnerable code. It also has not confirmed an active attack from this summary alone. BBC News described a response to defects. It did not, in the lines used here, publish a victim list or a single breached domain.

Urgency is a reason to check. It is not a reason to install a random archive from a forum post that claims to be the fix. The BBC News account supports a narrower action: find out if you depend on PHP, then follow the maintainers who actually ship the correction.

Sites that do not run PHP can still be neighbors to ones that do. A host, a plugin vendor, or a checkout provider may sit on the language even when your own templates do not mention it. That is why the question to the host is more useful than a guess from the page source. BBC News did not itemize those neighbors. The question is still the right size for the facts we have.

Until BBC News or the maintainers publish a version, a bulletin link, and a plain account of which hosts need a fix, this page will keep the action at one question to the host and one instruction to read the notice.

The story will keep moving as vendors publish details. Until those details are in a report this desk can link, they are not in this article. No CVE number appears here because none appears in the summary. No percentage of the web appears here because BBC News did not print one in that line.

Check the host. Read the notice. Ignore anyone who turns a missing version number into a scary certainty. BBC News gave the shape of a scramble, and the shape is enough to act on without pretending the fine print has already been copied onto this page.
